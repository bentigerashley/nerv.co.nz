Blue NERV screen rework

Reorient the existing standalone page around sparse title-card composition, show-like hex warnings, a cyan dotted phosphor field, and screen-by-screen navigation.

Grounding context

`nge11.gif` supplies a full-frame hexagonal alert field. `nge6.webp` and `nge7.webp` establish the requested cyan dotted phosphor texture, orange rails, diagonal masks, and separated display modules. The original site’s External Signals screen is a centered display heading above GitHub, Discord, and LinkedIn icons. `@mdrbx/nerv-ui` documents complementary primitives: TitleScreen, HexGridBackground, NavigationTabs, TargetingContainer, SystemDialog, and EmergencyBanner.

Topic axes

Warning gate · Screen hierarchy · Phosphor field and geometry · Directory presentation · Original external-signal ending

Ranked ideas

01. Full-frame hexagon warning gate

Description
Replace the card-based loader with an uninterrupted red/orange hex field, a central warning stamp, and an automatic timed transition. There is no skip or manual escape path.
Basis
direct: `nge11.gif` uses a dense wall of warning hexagons as the primary visual event.
Rationale
The first state reads as a title sequence, not a dashboard dialog.
Downside
It must stay brief and honor reduced motion so the gate does not become a barrier.

02. Three intentional screens

Description
Use viewport-height, snap-aligned landing, Directory, and External Signals screens. Each screen gets one job and a screen number rather than a dense dashboard of unrequested information.
Basis
direct: the user asked for landing, directory, and the original signals screen while explicitly deferring additional information.
Rationale
Screen composition makes the title-card typography and visual rhythm legible.
Downside
Content cannot grow indefinitely without adding a clear fourth screen later.

03. Cyan dotted phosphor field

Description
Build the global backdrop from layered radial dots, cyan haze, thin orange rails, and simple clipped geometric frames inspired by `nge6.webp` and `nge7.webp`.
Basis
direct: both supplied images use a dark cyan dot matrix behind orange, red, and mint modules.
Rationale
It gives the whole site a shared visual ground while leaving modules easy to read.
Downside
Keep contrast high enough that the dots never compete with type.

94%

04. NERV-UI patterns, no package install

Description
Translate the package’s TitleScreen, HexGridBackground, NavigationTabs, TargetingContainer, and SystemDialog patterns into the site’s dependency-free static implementation.
Basis
direct: the package documents those primitives, but its published peer dependencies require Framer Motion 11/12 and Tailwind 3.4/4 while this project uses Framer Motion 8 and Tailwind 3.2.
Rationale
The page benefits from the system’s composition language without destabilising the project for a single static page.
Downside
This is a visual translation, not a direct package integration.
